# Ciboo

Plan your lunches and dinners for the week.

- Type what you're having for each lunch and dinner; desserts can go on the same line ("Lasagne + tiramisù").
- Ciboo picks out the food groups from the name (veg, fruit, pulses, grains, fish, poultry, meat, sugar), including Italian dish names.
- Every meal you add is saved to **My meals**, sorted into Meat, Fish, Veggie and Dessert, so you can reuse it on any day.
- Jump to any week from the calendar.
- **Share this week** copies the week's menu as a message you can paste anywhere.

Meals are saved in your browser (localStorage), so each device keeps its own plan.

## Run it

It's a single static page: open `index.html` in a browser, or publish the folder with GitHub Pages.
